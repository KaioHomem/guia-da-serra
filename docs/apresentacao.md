# Roteiro da apresentação (até 10 minutos)

1. **Demonstração (2 min):** adicionar tarefas com prioridades, tentar enviar vazio (erro), marcar como concluída (confete), filtros, remover, recarregar a página (os dados continuam), tema escuro.
2. **Responsivo (1 min):** F12 > modo dispositivo > celular, tablet e desktop.
3. **Acessibilidade (2 min):** navegar só com Tab, Enter e Espaço; mostrar o link "pular"; rodar o Lighthouse (F12 > Lighthouse > Acessibilidade); se der, ligar o Narrador do Windows (Ctrl+Win+Enter) e mostrar o anúncio ao adicionar uma tarefa.
4. **HTML (1 min):** percorrer o `index.html` mostrando as tags semânticas.
5. **CSS (1 min):** variáveis de cor, tema escuro, media queries.
6. **JavaScript (2 min):** `tarefas.js` (regras) > `interface.js` (tela) > `main.js` (eventos, função `atualizar()`, delegação de eventos) > `efeitos.js` (animações).
